# MG4
## Devlog

The FloatAnimation script works by transforming the position of the object effected by the script along the Y axis. It has the start() function to make sure the _timer starts so the animation plays as soon as you start up the game. the Update() function is utilized to check the transformation position to see if it needs to send the object _up. All parts have to equally work for this seemingly simple animation to function properly
